# Workspace types and variants

One file per project type and per variant, listed by the new-workspace behaviour
(`ronin-help new-workspace`). A file of your own in `~/ronin/workspace_types/` adds a type or
variant, or replaces a stock one by name. Nothing else needs changing.

    # Title
    - **kind:** type | variant
    - **for:** who or what it is for, a few words
    - **order:** 10

    What the Workspace gets, or the choices it offers: one or two sentences.
