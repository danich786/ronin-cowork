# gbrain
- **label:** gbrain
- **blurb:** What authority and boundaries apply when the selected work uses GBrain?
- **class:** feature
- **requires:** behaviour:gbrain
- **order:** 90

Reach for this bundle only when the launch resolver selected the GBrain behaviour. It
grants the boundary teaching needed to work with that connected facility, but currently
projects no callable tool. Do not invent an operation, expose service credentials, or
route project facts through GBrain. Project facts use the Work Record's project read/write
tools, which are separate authority and are not represented as GBrain.
