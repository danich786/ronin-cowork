# Behaviours

One Markdown definition per selectable behaviour. A behaviour says how ordinary work is
done or adds a facility and its taught practice. `installation` names the system
installation that must be on before the behaviour is offered, or is blank for none.

Each definition may carry `label`, `blurb`, `installation`, `reading`, `sops`, `macros`,
`actions`, `tools`, `mcp`, and `order`. The definition page itself is always delivered
when selected; the other entries add supporting material to the same birth.
