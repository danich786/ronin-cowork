# Behaviours

One Markdown definition per behavior. A behavior says how ordinary work is done or adds
a facility and its taught practice. `scope` is `floor`, `conditional`, `selectable`, or
`situational`; only selectable behaviors appear as launch choices. `installation` names
the system installation required for application, or is blank for none.

Each definition may carry `label`, `blurb`, `scope`, `installation`, `reading`, `tools`,
`mcp`, and `order`. The definition page itself is always delivered
when selected; the other entries add supporting material to the same birth.
