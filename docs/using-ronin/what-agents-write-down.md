# Work records

A conversation scrolls away; a **work record** does not. Each Agent keeps one, and it is
what you read on its tile and in the roster to know what it is doing without asking.

## What an Agent writes down

- **What it is doing now**: its objective, in a line.
- **Where it works**: the folders and repositories it has open.
- **The work items it holds**: each one has an id like `w12`, a title, and a status colour: green going well, yellow in progress or waiting, red stuck.
- **Its ladder**: the steps of the work, each marked done or active, so progress is visible at a glance.
- **Its documents**: plans, notes and reports it wants you or the Team to read. They appear in the tile's Docs tab.

## Why it matters

A record is shared. The lead reads its Team's records to know who is where; you read
them to check on work you are not watching; a new Agent reads them to pick up where
another left off. Ask an Agent to "update your work record" whenever what you see does
not match what it told you.
